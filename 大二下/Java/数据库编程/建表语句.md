为了创建 `Books`、`Reader` 和 `Record` 表，你需要使用 SQL（Structured Query Language）来定义这些表的结构。以下是创建这三个表的 SQL 语句示例。你可以根据所使用的数据库系统对这些语句进行微调。

### 创建 Books 表

```sql
CREATE TABLE Books (
    ISBN VARCHAR(13) PRIMARY KEY,
    Title VARCHAR(255) NOT NULL,
    Authors VARCHAR(255) NOT NULL,
    Publisher VARCHAR(255),
    EditionNumber INT,
    PublicationDate DATE,
    Type VARCHAR(100)
);
```

### 创建 Reader 表

```sql
CREATE TABLE Reader (
    ReaderID INT PRIMARY KEY AUTO_INCREMENT, -- 注意：对于不支持AUTO_INCREMENT关键字的数据库，请使用相应的自增字段定义
    FirstName VARCHAR(100) NOT NULL,
    LastName VARCHAR(100) NOT NULL,
    Address TEXT,
    PhoneNumber VARCHAR(15),
    Limits INT -- 假设Limits表示借书上限数量
);
```

### 创建 Record 表

```sql
CREATE TABLE Record (
    RecordID INT PRIMARY KEY AUTO_INCREMENT, -- 同上，关于AUTO_INCREMENT的注意事项
    ISBN VARCHAR(13),
    ReaderID INT,
    BorrowingDate DATE,
    ReturnDate DATE,
    FOREIGN KEY (ISBN) REFERENCES Books(ISBN),
    FOREIGN KEY (ReaderID) REFERENCES Reader(ReaderID)
);
```

请确保在执行上述SQL语句之前选择了正确的数据库，并且你的数据库用户有足够的权限来创建表。此外，不同数据库管理系统（如MySQL、PostgreSQL等）可能需要稍微不同的语法来定义自增主键（例如，在PostgreSQL中使用`SERIAL`而不是`AUTO_INCREMENT`）。请根据你实际使用的数据库系统调整上述代码。
